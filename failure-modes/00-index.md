# Failure modes — adversarial analysis

One file per attack. The mechanism is only as good as its defense against these.

- `01-entrenchment.md` — early movers lock out newcomers
- `02-goodhart.md` — the metric becomes the gamed target
- `03-cold-start.md` — newcomers have no graph
- `04-granularity.md` — how you cut lanes determines everything
- `05-identity-fragmentation.md` — one human, many git identities (surfaced by the reference impl)
- `07-privacy-and-targeting.md` — the public ownership map is an attack map
- `08-cross-lane-gaming.md` — breadth-farming + drive-by lane claims
- `06-revert-war.md` — reverting rivals to destroy their weight

Stance: none of these are claimed *solved*. Each is raised, defended where the
defense is real, and its residual risk stated honestly. The goal is to raise the
cost of gaming above the cost of doing the work, not to be unbreakable.
